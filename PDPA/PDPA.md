## PDPA
**Collection Personal Data**
- notification of purpose of use and disclosing of personal data
- collection and use of data only within the scope of consent
- collection and use of data only within reasonable and appropriate bounds

**Care of Personal Data**
- ensure data is accurate if used or transferred
- make reasonable protections for data within your possession
- stop keeping personal data once it is no longer needed
- data transferred overseas to be kept with same standard as PDPA

**Individual autonomy over personal data**
- individuals to be provided access to their personal data and how it has been used and disclosed within a year
- notification of data breach to all affected individuals
- upon request, transfer all data to another organization in a common machine readable format

## Backup vs Archive
**Backup** - a copy of data used to restoration in case of damage / loss
**Archive** - a copy of data meant for long term storage and reference

| Backup                               | Archive                                        |
| ------------------------------------ | ---------------------------------------------- |
| rapid recovery of live changing data | stores unchanging data for long term retention |
| multiple copies                      | one copy                                       |
| restore speed is crucial             | Non imporant restoration speed                 |
| short term                           | long term                                      |
| overwritten                          | immutable                                      |
